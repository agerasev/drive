# Source history

Extracted with `git filter-repo` from `agerasev/games`, source tip
`dd03f659d825afb21f269d8d09fd48660d137175`. Original filenames are retained in historical commits,
including the earlier single-file game module and later directory layout.

`commit-map` maps original commit IDs to filtered IDs. An all-zero destination
means that the commit was pruned; it made no surviving change to the selected
files. Original author, committer, dates and messages are retained for surviving
commits. Shared helper modules retain their own history. Historical snapshots
are partial extractions and may not build independently.

`paths.txt` lists the exact paths selected by the filter.
